## 怎么问最容易得到靠谱答案

留言里带上这三样，我基本就能直接给你结论，省掉来回扯皮：

1. **预算区间**：比如 2000 上下、5000 以内封顶
2. **用途**：存照片 / 影音播放 / 监控录像 / Docker 与虚拟机 / 只是备份手机
3. **现状**：家里几口人、现在用什么设备、有没有现成的硬盘
