## 二、最重要的红线：不要全文搬运

**这一条优先级高于其他所有执行细节。**

知乎、smzdm、今日头条的域名权重都远高于 rhua.net。如果把这些文章原文复制过去，搜索引擎很可能判定**首发在平台、rhua.net 是转载**，结果是：本来属于自己站的排名，被平台抢走。这在 SEO 上叫站权重倒灌。

所以每一份稿必须遵守：

1. **摘录改写，不是复制。** 方法给足（读者觉得值），但完整的对照表格、机型清单留在站内
2. **每份稿至少 60% 是站上没有的新表达**（新例子、新结构、新比喻）
3. **核心数据表只给 2–3 行**，完整版用钩子引到站点
4. 平台上发完后，**确保 rhua.net 上那篇仍在更新**（更新时间戳是原创性的辅助信号）

## 三、引流链路：为什么不要直接放站点链接

三个平台对站外链接的容忍度，从高到低：什么值得买 > 知乎 > 小红书。但对一个新账号，全都危险 —— 新号直接放外链，最轻降权，最重删帖禁言。

**可行且更优的链路：小红书 / 知乎 → 公众号「Rhua NAS」 → rhua.net**

这条路的好处：
- 公众号是你自己的池子，**不会因为平台规则变动归零**
- 小红书主页简介写「公众号搜：Rhua NAS」是被广泛接受的做法
- 已经有竞品号在用这套打法（「NAS 奇思妙想」后台回复「清单」领资料）—— 说明可行，也说明**窗口正在关闭**

各平台具体钩子：

| 平台 | 钩子写法 | 禁用写法 |
|---|---|---|
| 小红书 | 主页简介写「完整选购表在公众号：Rhua NAS」；正文只说「对照表我整理好了，看简介」 | 正文放链接、写「看我主页」、评论区导流（会限流） |
| 知乎 | 昵称改为「Joey｜NAS 选型笔记」；回答末尾写「更多实测数据在个人主页」。**回答内不放链接** | 回答中段插站点链接（会被折叠） |
| 什么值得买 | 原创投稿允许放参考来源，可署「本文数据来自 rhua.net」 | 通篇放自己的商品推广链接 |

## 五、发之前先做两件小事（否则白干）

1. **改好再发**：小红书昵称/简介改成「NAS 选型笔记」相关；知乎昵称改成「Joey｜NAS 选型笔记」。这是唯一被允许、且效果最好的曝光位。
2. **看着"展现"不是"阅读"**：小红书笔记前 48 小时的「曝光→点击率」是唯一值得盯的指标。低于 5% 就是封面和标题的问题，**换标题比改正文有用十倍**。
